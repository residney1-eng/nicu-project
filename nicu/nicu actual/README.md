# NICU Noise Shield
The **NICU Noise Shield** is a neonatal intensive care unit (NICU) noise monitoring and alarm system designed to monitor environmental sound levels and support safer, quieter conditions for premature infants. The project uses microphones, real time sound processing, and a dashboard user interface to measure inside and outside noise levels, estimate active noise cancellation (ANC) reduction performance, and trigger visual alarms when unsafe sound levels are detected.

---

## Project Overview
- Real-time NICU noise monitoring
- Inside and outside microphones
- Adjustable microphone calibration offsets
- Active Noise Cancellation (ANC) reduction estimation
- Visual alarm system for unsafe noise levels
- Flashing alarm interface for loud environments
- Dashboard with noise data

---
